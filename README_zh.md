# LinkHelm

**把一部安卓手机共享出的网络，变成你其他设备能正常使用的网络——通过 Wi-Fi Direct，全程本地，云端不插手。**

LinkHelm 是一套小巧、自包含的工具链，只做一件明确的事：让一台 Windows 电脑使用安卓手机正在共享（Wi-Fi Direct / 网络共享）的网络，再把该网络二次共享给其他设备（Wi-Fi 热点或普通网线）。一切都在你自己的硬件上运行。数据链路上**没有服务器、没有账号、没有遥测、也没有任何第三方中转**。

两个应用，一套系统：

| 组件 | 是什么 | 运行位置 |
|---|---|---|
| **LinkHelm Host**（安卓 `.apk`） | 在手机 Wi-Fi Direct / 网络共享网络上，把手机变成一个本地 SOCKS5 端点。 | 安卓手机 |
| **LinkHelm Desktop**（Windows `.exe`） | 连接手机的 SOCKS5 端点，创建本地虚拟网卡，再把连接共享给其他设备。 | Windows 电脑 |

典型数据链路：

```
安卓手机（已共享 / 已网络共享）
      |  Wi-Fi Direct（SOCKS5，仅本地）
      v
Windows 电脑  -- LinkHelm Desktop -->  虚拟网卡（10.0.0.1）
      |
      |--->  Wi-Fi 热点    -->  笔记本、平板、游戏机……
      +--->  网线以太网    -->  台式机 / 交换机 / 路由器
```

## 它实际做了什么（简介）

现代手机可以通过 **Wi-Fi Direct** 共享其移动 / Wi-Fi 连接。LinkHelm 让这份共享出来的连接能被整台电脑使用，并通过电脑再被一切其他设备使用：

- **LinkHelm Host（安卓）** 在手机侧发布一个本地 **SOCKS5** 代理，绑定在 Wi-Fi Direct 网络上，使用一组固定、可改的用户名 / 密码（8–13 位字母数字）。它从不向公网开放任何端口。
- **LinkHelm Desktop（Windows）** 拨号连接该 SOCKS5 端点，拉起本地虚拟网卡（Wintun），安装通往互联网所需路由，再把这条上行共享给其他设备——可以是 **Windows 移动热点**，也可以是**有线以太网**适配器。客户端设备**完全无需任何代理配置**，它们只看到一个普通网络。

结果：手机的网络变成了一个任何设备都能加入的普通 Wi-Fi / 以太网网络。

## 环境要求

### Windows（LinkHelm Desktop）
- Windows 10/11（64 位）。正常使用无需管理员；仅在需要配置共享 / 路由时才会请求提权。
- 已内置 lwIP 引擎（`hev-socks5-tunnel` + `Wintun`）组件，运行时不会下载任何东西。
- 若要共享：需要一个支持移动热点的 Wi-Fi 网卡，**或**一块有线以太网网卡。

### 安卓（LinkHelm Host）
- Android 8.0（API 26）及以上。
- 支持 Wi-Fi Direct 的硬件。

### 一张要共享的手机网络
- LinkHelm 承载的是**手机已经拥有的那张连接**（它的移动数据，或它连上的某个 Wi-Fi）。它本身不产生网络。

## 快速开始

### 1. 安卓——启动主机
1. 安装 **LinkHelm Host**（`LinkHelm-Host-Android-*.apk`）。
2. 打开它，授予所请求的权限，点击 **启动主机**。
3. 记下显示的 **SSID 和密码**（可在设置中修改）。
4. 保持手机在前台。此时手机已成为其 Wi-Fi Direct 网络上的一个本地 SOCKS5 端点。

### 2. Windows——连接
1. 运行 **LinkHelm Desktop**（`LinkHelm_Desktop.exe`）。
2. **第 1 步——入站：** 填入**手机 IP**（默认 `192.168.49.1`）、**SOCKS5 端口**（默认 `8080`）以及 SOCKS5 用户名 / 密码（默认值与 App 一致）。先在 Windows 上加入手机的 Wi-Fi Direct 网络，然后点击 **连接**。
3. **第 2 步——出站：** 选择 **Wi-Fi 热点** 或 **以太网**，点击 **开始共享**。
4. 在其他设备上，加入该热点 SSID（或插上网线）——无需任何代理设置。

简明操作指引见 [`docs/MANUAL.md`](docs/MANUAL.md)。

## 设置（两个应用）

- **语言** —— 在 **中文** 与 **英文** 之间切换界面。Windows 端会立即重启以使全局（含托盘）生效；安卓端即时生效。
- **开机自启**（Windows）—— 登录后自动启动，最小化到托盘。
- **自动连接**（Windows）—— 静默自启后，当手机代理出现时自动连接。
- **SOCKS5 账号**（两端）—— 修改用户名 / 密码（8–13 位字母数字）。立即生效；若当前有连接，隧道会实时重建。
- **Wi-Fi SSID / 密码**（安卓）—— 你电脑所加入的热点。
- **ICS 诊断**（Windows）—— 只读检查共享服务与到手机的路由，不做任何改动。

## 安全说明

- **仅本地。** SOCKS5 端点绑定在手机与电脑之间的 Wi-Fi Direct 链路上，互联网无法访问。
- **固定但可改的凭据。** 初始用户名 / 密码两端一致且永不随机化。若与他人共享网络，请在设置中修改。
- **已校验的二进制。** 内置的 `hev-socks5-tunnel` / `Wintun` 引擎文件在使用前会按固化的 SHA-256 值校验。
- **ICS 诊断为只读。** Windows 诊断永远不会修改共享配置。

## 常见问题（FAQ）

**这能隐藏我的 IP 或充当 VPN 服务器吗？**
不能。它只是把电脑的流量从你自己的手机现有连接转发出去，并非远程 VPN。

**我能把它指向别的 SOCKS5 服务器吗？**
不能。上游被刻意限制为你自己网络共享的手机。

**客户端设备需要设置代理吗？**
不需要。它们加入的是普通热点 / 以太网网络。

**Windows 提示「已经在运行」。**
同一时间只能运行一个实例（两个会抢路由和共享）。请从托盘的 **退出并清理网络** 退出第一个。

**热点一直不出现 / 共享失败。**
在 Windows 设置里运行 **ICS 诊断**（只读），检查到手机的路由。先确认电脑已加入手机的 Wi-Fi Direct 网络。

**语言没有切换。**
Windows：会自动重启；若没有，重新打开设置。安卓：即时生效。

## 致谢与说明

LinkHelm 是在 nestchao 的开源项目 **Hotspot-Bypass-VPN-Unlimited-Hotspot** 基础上衍生的作品。

- 原项目：<https://github.com/nestchao/Hotspot-Bypass-VPN-Unlimited-Hotspot>

LinkHelm 保留了原项目的核心思路——通过 Wi-Fi Direct + SOCKS5 代理在本地共享手机连接，但进行了大量重写与扩展。相对于原项目，主要提升如下：

- **双端统一 lwIP 引擎** —— 旧 tun2socks 内核被彻底替换为原生 lwIP 栈引擎（HevSocks5Tunnel 2.19.1）：TCP/UDP/DNS 由同一内核在安卓与 Windows 两端统一处理，二进制按固化 SHA-256 校验，运行时无下载、无回退路径。
- **TCP 与 UDP 连接稳定性增强** —— 在游戏 / 高 UDP 负载等场景下，对连接生命周期、空闲保活、重传的处理更加稳健。
- **多 DNS 备选** —— 依次尝试多个 DNS 服务器，当其中一个不可达时解析仍能继续。
- **SOCKS5 账号密码认证（RFC 1929）** —— 主机强制用户名 / 密码认证，不再存在开放、未认证的端口。
- **大幅度提高并发能力** —— 更高的工作线程上限与按客户端配额管理，让多设备同时共享而不会饿死后来的连接。
- **双通道（主 + 备通道）** —— 额外通道保持连接存活，在拥堵时优雅降级。
- **重写了大部分代码** —— 代理引擎、Windows 客户端与安卓主机都进行了远超原项目的重构。
